# Project data, attribution, and reuse notice

This is a bounded MS_DSP_462 computer-vision course project, not a production moderation service. The canonical local project contains the complete 315-image working set. Public Git contains the runnable source code, two trained policy heads, saved model and evaluation evidence, an executed notebook, the original proposal, the final report, the PowerPoint presentation, the narrated demonstration video, and the dataset files cleared for this release.

## Dataset boundary

The formal dataset contains 288 images:

- 72 safe-class images selected from `EthanGabis/ADautoGen-DS` remain local-only. The pinned upstream repository does not provide supported license metadata or a license file that establishes redistribution permission for these selected images;
- 144 firearm and explosive images selected from `rajshivanshuu/weapons_set1` remain local-only. Repository-level license metadata does not provide the missing per-image origins and rights records; and
- 72 deterministic financial-promotion creatives generated by this project's Python builder are tracked in public Git as course artifacts at the repository owner's direction. Their inclusion does not grant a dataset reuse license.

The 216 third-party formal images are present in the canonical local project, but their standalone normalized dataset files are excluded from public Git because their redistribution terms or item-level provenance are insufficient. Their registry rows remain public so the exact sources, revisions, grouping rules, and expected local hashes can be audited. Reconstructing them from an upstream source does not grant redistribution rights.

Tracked course records may contain bounded screenshots, thumbnails, or annotations derived from selected local-only examples. This includes notebook output, evaluation and demo figures, app screenshots, the report, the presentation, and the video. Publishing those records does not repair the underlying rights gap or grant permission to extract, reuse, or republish an embedded image.

The separate Wikimedia collection contains 27 local candidates. Manual review retains 26 relevant images for the external diagnostic and excludes one title-search collision with no visible explosive content. The 26 retained images are tracked in public Git. `data/dataset_registry.csv` records all 27 candidates, and `data/wikimedia_external_manifest.csv` records the review decision. Public-domain, CC BY, and CC BY-SA items remain subject to their item-specific attribution and share-alike requirements in `data/WIKIMEDIA_ATTRIBUTION.md`.

The canonical registries are:

- `data/capstone_registry.csv` for the 288-image formal dataset;
- `data/capstone_dataset/dataset_manifest.json` for split counts, source revisions, and known limitations;
- `data/dataset_registry.csv` for the 27 Wikimedia candidates;
- `data/wikimedia_external_manifest.csv` for the 26 retained candidates and one exclusion; and
- `data/WIKIMEDIA_ATTRIBUTION.md` for the retained files' item-level attribution and license notices.

Repository-level license metadata does not prove that an upstream dataset publisher held every right needed for every image. Anyone republishing an included image must review its recorded source, applicable license, attribution, and share-alike obligations. The repository makes known gaps visible; it does not cure them.

## Contributor-identified deliverables

The notebook, report, presentation, video, book configuration, and their builders identify the course contributors. Publishing this repository makes those names and the coursework publicly visible. Reusers must not imply that a contributor endorses a reuse, product, or moderation decision.

## Model and code safety

Pretrained backbone caches are not tracked. Bootstrap downloads only the revisions recorded in `models/pretrained_model_manifest.json` and verifies their snapshot fingerprints.

The included `joblib` policy heads use Python's pickle mechanism, so a modified or substituted file could execute code during deserialization. Run `python scripts/preflight.py --profile core` before inference. The runtime repeats the size and SHA-256 check before calling `joblib.load`; expected values are in `models/trained_head_manifest.json`.
